登录成功后，后续请求如何携带并识别用户标识

数据来源：Chrome DevTools Protocol 从真实浏览器会话抓取的网络日志（Network.requestWillBeSentExtraInfo / responseReceivedExtraInfo），未做改写。

① 登录请求：服务端把会话标识放进 Set-Cookie

POST http://127.0.0.1:8088/api/login
请求头 Cookie（无）
响应头 Set-Cookiecampusclaw_session=QqLOUhqtrfJfY3wGa4dLTJCTzlqGd90wwq4JLeuztuY; Path=/; Max-Age=230400; HttpOnly; SameSite=Lax

② 之后获取本班材料：浏览器自动带上 Cookie

GET http://127.0.0.1:8088/api/materials
请求头 Cookiecampusclaw_session=QqLOUhqtrfJfY3wGa4dLTJCTzlqGd90wwq4JLeuztuY
响应头 Set-Cookie（无）

可以看到：登录响应通过 Set-Cookie 下发 campusclaw_session（HttpOnly，脚本读不到）；随后 GET /api/materials 的请求头里自动携带同一个 Cookie——浏览器没有任何 JavaScript 代码去读取或拼接这个标识。
