④ 校验：库里那行 = HMAC-SHA256(SESSION_SECRET, token)

===== 4) 验证：库里这行 = HMAC-SHA256(SESSION_SECRET, token) =====
计算出的 HMAC = 0185459de425bfb206e347b54351e24bc07de7a71e64bbf72a2c9cd7a455c7b0
库中的     id = 0185459de425bfb206e347b54351e24bc07de7a71e64bbf72a2c9cd7a455c7b0
结论：库中保存的是 token 的 HMAC，不是 token 本身 ✔
