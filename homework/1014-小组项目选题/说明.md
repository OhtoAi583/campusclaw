# 1014 小组项目选题

**交付物**：`小组项目选题说明.pdf`（5 页）

- `小组项目选题说明.md`：内容源文件（Markdown）
- `build_pdf.py`：由 Markdown 生成 PDF 的脚本，改完内容重跑一次即可
- `预览/`：5 页渲染预览图

## 内容结构（对照作业要求）

| 作业要求 | 文档位置 |
| --- | --- |
| 1. 项目题目 | 文首「项目题目」+ 一、选题背景 |
| 2. 主要功能 | 二、主要功能（A 知识库升级 / B 智能备课 / C 教研协作 / D 学情反馈，共 12 项，标注 P0–P2 优先级与验收要点） |
| 3. 技术方案 | 三、技术方案（架构图、技术栈表、5 项关键设计决策含备选与否决理由、4 个迭代计划、质量门禁） |
| 4. 小组成员及分工 | 四、小组成员及分工（成员表 + 按角色的分工表 + 单人小组的协作验证机制） |
| 附加 | 五、风险与应对；六、交付物 |

## 生成与校验

```bash
python3 build_pdf.py                 # 重新生成 PDF
pdftoppm -r 90 -png *.pdf 预览/p      # 渲染页面
```

已校验：5 页、四个必需章节齐全、**PDF 文字层可正确提取中文**（Chrome 导出的版本会把"项目"映射成康熙部首，
已改用 reportlab 生成）、排除页脚后文本越界 0 处。
