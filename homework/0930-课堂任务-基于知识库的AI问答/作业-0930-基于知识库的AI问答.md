# 0930 课堂任务：基于知识库的 AI 问答

**实现效果**：新增 `POST /api/ask` —— **先在本班检索，取得切片之后才生成回答，并标注出处**；
没有命中切片时**不调用生成模型**，直接返回固定文案与空 `citations`。截图见本目录 `截图/`（3 张浏览器实测）。

演示页：`/ask-demo.html`

## 一、链路（与第 4 课课件一致）

```
用户提问（只用最新这一句）
   ↓  本班混合范围检索（class_id 取自会话，取前 4 条）
有切片？ ── 否 ─→ 直接返回「资料中未找到相关内容」，citations = []，不调用生成模型
   │
   是
   ↓  组装：材料标题 + 切片序号 + 切片正文 + 编号
生成模型 → 回答中用 [1] [2] 指回出处
   ↓
返回 answer + citations（顺序与 [编号] 一一对应）
```

## 二、接口

```
POST /api/ask          （需要会话或 Bearer 令牌）
{ "question": "导入环节为什么要用情境图？", "top_k": 4 }
```

```json
{
  "answer": "根据本班材料，就「导入环节为什么要用情境图？」可以找到以下依据：\n1. 导入环节用一张生活情境图引发预测，目的是把学生的注意力拉到「内容会怎么发展」上， [1]\n\n（以上内容摘自本班材料，点击出处可回到原文核对。）",

      "start_offset": 320, "end_offset": 588, "snippet": "…", "score": 0.282 },
    { "index": 2, "…": "…" }
  ],
  "model_called": true,

}
```

## 三、实现要点

1. **先检索再生成**：`internal/answer` 只调用 `search.Service`（本班范围）拿切片；拿不到就走固定文案分支，
   `model_called=false`、`citations=[]`，**完全不进入生成环节**——避免模型凭参数记忆硬答天气、比分一类问题。
2. **交给模型的只有**：材料标题、切片序号、切片正文、用户提问（`BuildPrompt`）。
   **不传**向量分量、不传其他班级切片；客户端自己构造的 system 消息无法进入这条链路（接口不接受该字段）。
3. **出处顺序与标注一致**：`citations[i].index = i+1`，与回答中的 `[1] [2]` 顺序严格对应；
   前端点击出处可回到材料详情并高亮该字符区间（迭代 2 已实现）。
4. **生成实现可替换**：`ChatClient` 接口 + 本地摘录实现（`local-extractive`）。
   本地实现把命中的切片按句摘出来拼成简短回答，**内容全部来自检索结果，不凭空生成**，因此同样可溯源；
   配置好对话网关后换成真实模型实现即可，接口契约不变（`engine` 字段会体现本次由谁生成）。
5. **班级隔离沿用**：问答走的是同一套 `RequireAuth` + 会话班级，跨班内容不会进入候选集，
   表现为 200 + 固定文案（不是 403/404，避免暗示"这资料属于别的班"）。
6. **日志只记必要字段**：`user_id`、`class_id`、问题长度、citations 数、是否调用模型、耗时；
   不记问题原文与切片正文。

## 六、真实模型接入（已配置）

回答生成已接入 **DeepSeek**（兼容 OpenAI 的 `/chat/completions`）：

| 配置项 | 值 |
| --- | --- |
| `CHAT_API_BASE` | `https://api.deepseek.com` |
| `CHAT_MODEL` | `deepseek-chat` |
| `CHAT_API_KEY` | 只放在服务端 `.env`（已被 gitignore），不下发浏览器、不入库 |

- `engine` 字段会显示本次由谁生成：`gateway:deepseek-chat`（真实模型）或 `local-extractive`（未配置密钥时的离线降级）。
- 未配置 `CHAT_API_KEY` 时自动退回本地摘录实现，便于离线复现；配置后无需改代码。
- 实测：问「导入环节为什么要用情境图」，模型依据 `[1]`（A 班材料第 2 块）与 `[2]`（第 1 块）作答，
  每一条结论后都带编号；问「今天上海天气怎么样」时检索无命中，**不调用模型**，返回固定文案。

## 七、局限（写清楚，不藏）
- 检索质量受迭代 2 的嵌入方案限制（词形相似，非语义泛化），问法差异过大时可能落到"无依据"分支。
- 本课不做流式输出与多轮对话，`history` 未纳入（课件明确留到第 5 课）。
